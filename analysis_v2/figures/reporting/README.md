# Reporting Figure Folders

This folder is a curated copy of current analysis figures, organized for review and writing.
Original figure paths are left in place so existing notebooks continue to run.

- `session-level/`: Stage 6 session-outcome prediction figures.
- `person-level/`: Stage 7 person-level team/funded-team prediction figures.
- `temporal-windows/`: Stage 8 first/last window prediction figures.
- `validation/`: human/Gemini agreement figures.
- `sampling/`: validation-sample distribution figures.
